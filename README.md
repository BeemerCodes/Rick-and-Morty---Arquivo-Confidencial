## 🌌 De onde veio essa ideia?

Tudo começou com uma proposta da disciplina de **Web Development Front-End** da **UniFECAF**: consumir a API pública usando JavaScript puro e mostrar os personagens na tela com `document.createElement`.

O universo da série é caótico demais pra ficar só numa listinha de fotos. O projeto acabou ganhando vida própria:
* **Zero Frameworks:** Nada de React, Vue, Vite ou 500 MB de `node_modules`. É HTML, CSS e Vanilla JS paizão.
* **Dois Cliques:** Roda direto no navegador com duplo clique no arquivo, sem precisar subir servidor ou compilar nada.
* **Eu ouvo:** Sons em 8-bit sintetizados no próprio código, efeitos 3D ao passar o mouse e uma adaptação pensada com carinho para a tela do celular.

## ✨ O que tem de bom por aqui?

### 🧬 Status de RPG Determinísticos
Nada de valores aleatórios que mudam a cada F5. A Vida, Força, Inteligência e Sorte de cada personagem são calculados matematicamente a partir dos dados oficiais da API (ID, tamanho do nome, espécie e episódios). O Rick sempre terá inteligência nas alturas e o Jerry... bem, os números não mentem.

### 🥊 Arena Rogue-Like por Turnos
* Recrutamento com 42 candidatos mesclando seus favoritos e novos encontros pelo caminho.
* Dreno de cor no card conforme a vida cai, mostrando o guerreiro ficando sem forças.
* 30 cartas de buffs com gosma de portal em SVG, dano refletido e até ressurreição angelical.

### 📻 Rádio Interdimensional
Um player discreto no topo com 5 frequências espaciais ao vivo e uma faixa secreta desbloqueável.

### 🛡️ Cache Inteligente Anti-Stress
Se a API resolver limitar requisições (*HTTP 429 Too Many Requests*), a aplicação não quebra: ela ativa automaticamente o cache em memória e um time reserva de personagens canônicos para você continuar jogando sem sustos.

## 🚀 Como Rodar o Projeto?

Você não precisa instalar nenhuma dependência, pacote ou terminal Hackeerrr.

1. Baixe ou clone este repositório.
2. Dê um **duplo clique** no arquivo `Confidential/index.html`.
3. Pronto! Abre direto em qualquer navegador.
